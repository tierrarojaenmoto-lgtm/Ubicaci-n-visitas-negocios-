1. Clave de Google

¿Cómo consigo la clave?
  1. Entrá a console.cloud.google.com con tu cuenta de Google y creá un proyecto.
  2. Activá la facturación (piden una tarjeta, pero hay un uso mensual gratis por tipo de búsqueda).
  3. En "APIs y servicios" activá Places API (New).
  4. En "Credenciales" creá una clave de API.
  5. Restringila: solo para Places API y solo para la dirección web donde alojes esta página.
  6. Poné un presupuesto con alerta (ej. USD 5) y una cuota diaria baja para evitar sorpresas.
La clave se guarda solo en tu celular y nunca va dentro de este archivo.
